# 📡 MEMORIE IN SPACE | El Códice del Espacio Profundo

**Proyecto desarrollado por el Equipo Nova Itsat para el NASA Space Apps Challenge.**

## 🌌 Descripción del Proyecto
**MEMORIE IN SPACE** es una aplicación web interactiva y bilingüe (Español / Inglés) diseñada para la divulgación científica infantil y juvenil. A través de la historia de **Mateo** (un niño de 10 años que descubre la bitácora de su abuelo, antiguo ingeniero de la Estación Rastreadora de Guaymas, Sonora), los usuarios exploran el vínculo histórico entre la astronomía mexicana y las misiones robóticas de la NASA en la Luna y Marte.

### ✨ Características Principales
* **Storytelling Interactivo:** Introducción narrativa que conecta la herencia astronómica mesoamericana y la Estación de Guaymas con la exploración espacial moderna.
* **Mapas Interactivos Duales (Luna y Marte):** Balizas responsivas con información técnica sobre hardware, descubrimientos científicos y cápsulas culturales *Puente Estelar México–NASA*.
* **4 Minijuegos Educativos en HTML5 Canvas:**
  1. *Surveyor 3:* Calibración de excavación en Oceanus Procellarum.
  2. *LRV Apolo 15:* Recolección de la Roca del Génesis esquivando cráteres.
  3. *Opportunity:* Alineación de antena durante la tormenta global de polvo de 2018.
  4. *Ingenuity:* Vuelo propulsado en la tenue atmósfera del cráter Jezero.
* **Audio Sincronizado e Interfaz Bilingüe (`ES / EN`):** Cambio instantáneo de idioma para accesibilidad global.

## 🛠️ Arquitectura y Tecnologías
* **Frontend:** HTML5, Tailwind CSS (CDN), JavaScript Vanilla (ES6+).
* **Gráficos y Audio:** HTML5 `<canvas>` API y Web Audio API sin dependencias pesadas.
* **Despliegue:** Integración continua en Vercel desde GitHub.
